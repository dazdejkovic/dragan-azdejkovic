# Prilagođavanje sajta

Najvažniji fajlovi:

- `_config.yml` — ime sajta, GitHub adresa i naziv repozitorijuma;
- `_pages/about.md` — početna strana;
- `_pages/biography.md` — biografija;
- `_pages/teaching.md` — pregled predmeta;
- `_teachings/*.md` — pojedinačni predmeti;
- `_pages/mentorship.md` — master i doktorski radovi;
- `_bibliography/papers.bib` — publikacije;
- `_data/socials.yml` — e-pošta, ORCID i Google Scholar;
- `assets/img/Dragan-Azdejkovic-2.webp` — profilna fotografija.

U `_config.yml` zamenite `USERNAME` svojim GitHub korisničkim imenom i podesite `baseurl` prema nazivu repozitorijuma.
